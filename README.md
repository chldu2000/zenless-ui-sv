# Zenless UI Svelte

Zenless UI 的 Svelte 5 组件库迁移版本。目前完成了库打包、文档站、质量门禁和消费端验证骨架；组件将在后续迁移阶段逐步加入。

## 开发

```sh
corepack pnpm install
corepack pnpm dev
```

## 校验

```sh
corepack pnpm lint
corepack pnpm check
corepack pnpm test:unit
corepack pnpm build
```

完整迁移路径见 [SVELTE_MIGRATION_PLAN.md](./SVELTE_MIGRATION_PLAN.md)。
